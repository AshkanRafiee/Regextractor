# Regextractor

Offline Android app that builds regular expressions from highlighted text examples with live match preview. Fully offline, no permissions, no tracking.

## Build

```sh
bash ./gradlew assembleDebug
```

## Test

```sh
bash ./gradlew testDebugUnitTest
```
